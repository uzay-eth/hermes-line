## 1. What was built (`plugin/line/voice/`, standard library + `websockets` at runtime)

| Module | Role |
|---|---|
| `provider.py` | `RealtimeVoiceProvider` interface: `connect(config)`, `update`, `send_audio`, `recv` (typed events), `add_context`, `respond`, `say_exact`, `send_tool_result`, `truncate`, `cancel`, `close`. `SessionConfig` has two purposes: `speech` (fixed lines only) and `conversation`. Default WebSocket client is `websockets` (lazy import). |
| `grok.py` | `GrokRealtimeProvider`: `wss://api.x.ai/v1/realtime?model=grok-voice-latest`, `audio/pcmu` in/out, server VAD, function tools, `force_message`, `function_call_output`, `conversation.item.truncate`. Tool calls are deduplicated across `function_call_arguments.done` and `output_item.done`. It reads `XAI_API_KEY` through the injected `get_secret` at connect time only. |
| `stt.py` | `Transcriber` interface; `XaiStreamingTranscriber` (`wss://api.x.ai/v1/stt`, µ-law 8 kHz binary frames, final = `is_final && speech_final`). These are the cheap ears during IVR and hold. |
| `mediastreams.py` | `MediaStreamBridge`: Twilio bidirectional stream, µ-law passthrough (no transcoding), format/CallSid/frame-size validation, `media`/`mark`/`clear` out, `dtmf`/`mark`/`stop` in. `clear` drops unsent audio and reports cleared marks. |
| `gate.py` | `SessionGate` (when a voice session may exist, decided from L1 state) and `ConnectionMeter` (connected seconds on an injectable clock). |
| `tools.py` | The 7 tools Grok gets, the `CallPort` protocol L1 implements, and `ToolRouter` (validation, single-flight, per-minute budget, masking). |
| `dtmf.py` | Round 2. The menu-key fallback: `DtmfFallback` (one-time digit plans behind a nonce, refused for any digits that are or contain a released code; `SealedGuard` keeps per-call keyed hashes, never the code) and `menu_did_not_react` (the "menu ignored the tones" signal, §2 point 9). |
| `phrases.py` | `PhraseCache`: rendered fixed lines and digit-word clips, in memory, never text containing digits. |
| `controller.py` | `VoiceCall`: ties the parts together. Towards L1 it behaves like a ConversationRelay socket (`offer` setup/prompt/dtmf/interrupt; accepts text/sendDigits/end). Also handles barge-in, in-band DTMF, sealed codes, reconnects and the idle-to-hold watchdog. |
| `settings.py` | `VoiceSettings.load(dict)` (strict) and `select_transport(settings, get_secret)`, which returns `media_streams` with a key, `conversation_relay` without one, and `refused` if forced without a key. |
| `twiml.py` | `play_digits_then_stream(...)` (round 2: `<Play digits>` + `<Connect><Stream>`); `connect_stream(...)`: `<Connect action><Stream url><Parameter name="call"/></Stream></Connect>`. It refuses query strings and non-`wss` URLs. |
| `testing.py` | Fakes: `FakeRealtimeProvider`/`FakeProviderHub`, `FakeMediaStreamsClient` (Twilio's side, mark echo on `clear`), `FakeTranscriberHub`, `FakeWs` + `fake_connector`, `VirtualClock`. |

ConversationRelay is untouched and remains the transport whenever `select_transport` says so.

1. **Config and manifest (`plugin/plugin.yaml`, `line/engine/config.py`).**
   - `requires_env` += `{name: XAI_API_KEY, description: "xAI API key for Grok Voice (optional; without it calls use
     ConversationRelay)", url: "https://console.x.ai", secret: true}`.
   - `python_dependencies` += `"websockets>=15,<16"` (a Hermes core dependency at Python ≥ 3.14, but declare it per the
     contract).
   - `config_schema.voice: {type: object}` → `EngineConfig.voice: dict`, validated with
     `line.voice.VoiceSettings.load(cfg.voice)`.
   - UNCONFIRMED: whether a missing `requires_env` entry blocks loading for a non-platform plugin. L1 already
     declares the optional `HERMES_LINE_TWILIO_AUTH_TOKEN` the same way. The manifest also accepts `optional_env`
     (`hermes_cli/plugins_manifest.py:34`).
2. **Transport choice per call.** In `CallService.request_call` and `on_inbound`, call
   `line.voice.select_transport(self.voice_settings, self.get_secret) -> TransportChoice(transport, reason)`. On
   `refused`, fail the request before approval. Store the choice on the call.
3. **TwiML.** Add `CallService.connect_twiml(self, session: CallSession, *, welcome: Optional[str]) -> str`, used
   everywhere `relay_twiml` is used today (answer, inbound, `relay_action` reconnect). For Media Streams it returns
   `line.voice.twiml.connect_stream(ws_url=self.ws_url(f"/twilio/media/{call_id}/{token}"),
   action_url=self.url(f"/twilio/voice/connect/action/{call_id}?g={N}"), call_id=call_id)`, with
   `token = self.issue_stream_token(call_id, f"media-g{N}")` for the next stream generation `N` (round 3: as
   wired by L1 in `CallService.connect_twiml`, docs/lanes/L1.md §12).
   - The token goes **in the path**: `<Stream url>` takes no query string. `url()`/`ws_url()` already add L1's
     per-install path secret (`/t/<secret>`).
   - There is no `welcomeGreeting`; the disclosure is `VoiceCall(welcome=...)`.
4. **Ingress route.** Add `WebSocketRoute("/t/{secret}/twilio/media/{call_id}/{token}", stream)` with the same
   authentication as `relay` (signature over the `wss` URL when the Auth Token is present; path secret + one-time
   token + `leg_expectation` REST check otherwise). Then:
   ```python
   if not svc.claim_stream_token(call_id, token, f"media-g{session.relay_gen}"): close(1008)   # current generation only
   session = svc.sessions.get(call_id); await ws.accept()
   link = RelayLink(session.voice.engine_frame, session.voice.engine_close)
   if not session.attach_relay(link): close(1008)
   try: await session.voice.serve(ws)            # Starlette WebSocket fits StreamSocket
   finally: link.closed = True; session.relay_closed(link)
   ```
5. **Creating the voice call.** `CallSession.voice: Optional[VoiceCall]`, created in `_dial` and `on_inbound` when the
   transport is `media_streams`:
   ```python
   VoiceCall(call_id=call.id, port=CallSessionPort(self, session),
             provider_factory=lambda: GrokRealtimeProvider(self.get_secret, model=vs.model),
             transcriber_factory=lambda: XaiStreamingTranscriber(self.get_secret, endpointing_ms=vs.stt_endpointing_ms, language=vs.language),
             settings=vs, phrases=self.phrases,                      # one PhraseCache per CallService
             welcome=cfg.disclosure() if outbound and self.disclosure_on else (self.inbound_greeting(task) if inbound else None),
             instructions=self.briefing(task, direction), mask=mask_text, expected_call_sid=provider_sid)
   ```
   For an outbound call, `expected_call_sid` is the SID returned by `place_call`; set it on `session.voice` before
   the stream connects.
6. **Hooks in `CallSession`.**
   - `set_state(...)` and `finalize(...)`: after the state is stored, call `if self.voice: self.voice.on_state(new.value)`.
     This is mandatory, because the gate depends on it. The rehearsal wires it through `svc.notifier`.
   - `_on_human(text)`, agent mode, `voice.settings.conversation == "grok"`: `await self.set_state(AGENT_TALKING)`,
     then `await self.voice.begin_conversation(f"A live person is on the line now. They said: {text}")`, **instead of**
     `start_turn`. Do the same in the `owner_unavailable` agent fallback and for inbound callbacks after setup. In
     `hermes_text` mode, keep today's `start_turn`; `VoiceCall` reads Hermes's text aloud.
   - `send_secret(secret, mode)`: if `self.voice`, return `await self.voice.send_sealed(secret, mode)` and keep the
     marker, event and note lines. Until this is wired, a sealed `text` frame is still never sent to the model:
     `VoiceCall` recognises the spaced-code shape and plays cached digit clips or refuses. DTMF already goes out as
     local tones.
   - `_allow_code(...)` with destination `call`: spawn `session.voice.prepare_sealed_speech()`, which renders the ten
     digit words into the cache without playing them.
   - New: `async def voice_hold_resumed(self) -> dict`. Allow `AGENT_TALKING → ON_HOLD` in `ALLOWED`, reset
     `self.tracker = deps.HoldTracker(ask_model=self._ask_model)` and `self.last_confirm = -math.inf`, then
     `set_state(ON_HOLD, "hold resumed")`.
   - Optional: after `_maybe_confirm` asks the live-person question, call `self.voice.prewarm()` (only acts when
     `voice.prewarm_s > 0`; default off).
7. **`CallPort` (L1 implements; see `line/voice/tools.py`).**
   ```python
   call_id: str
   def offer(self, frame: dict) -> bool                     # CallSession.offer
   def record(self, speaker: str, text: str) -> None        # _transcript(Speaker(speaker), mask_text(text))
   def voice_event(self, kind: str, **data) -> None         # _event
   async def ask_hermes(self, question: str, timeout_s: float) -> Optional[str]   # one driver.turn on the call worker, masked text
   async def bring_owner(self) -> dict                      # ring_owner("agent_request") → {"ok": bool, "error"?}
   async def press_digits(self, digits: str) -> dict        # press_digits
   async def report_outcome(self, outcome: str, summary: str) -> dict  # request_finish
   async def end_call(self) -> dict                         # hang_up(COMPLETED)
   async def send_verification_code(self, mode: str) -> dict  # L4 OtpDelivery.to_call(task_id, call_id, mode, svc.otp_token(task_id), svc.consent) → status only
   async def hold_resumed(self) -> dict                     # voice_hold_resumed
   async def voice_failed(self, reason: str) -> None        # hang_up(PROVIDER_ERROR, state=FAILED)
   async def redirect_digits(self, nonce: str) -> dict      # DTMF fallback, point 9 (optional; without it no fallback)
   ```
   `ask_hermes` must prefix the question as coming from the voice agent and keep it untrusted, for example
   `"[voice agent asks, relaying an untrusted caller] …"`. It must never return a code.
   `press_digits` keeps `CallSession.press_digits`'s state, shape and one-press-per-prompt checks, the
   `Pressed …` transcript line and the `dtmf_sent` event, but instead of `self._send({"type": "sendDigits", ...})`
   it returns `await self.voice.press_menu(digits)` (point 9).
9. **DTMF fallback (round 2).** Menu keys are in-band tones first. If the menu does not react, `VoiceCall`
   sends the same keys once more by briefly leaving the stream, and every later press on that call goes the same
   way. L1 makes four calls; nothing else changes:
   - **Menu presses:** in `CallSession.press_digits(digits)`, after its existing checks, call
     `result = await self.voice.press_menu(digits)`, which returns `{"ok": True, "via": "tones"|"redirect"}` or
     `{"ok": False, "error": str}`. Return that result to the tool. Do **not** also send a `sendDigits` frame.
   - **Redirect:** `CallPort.redirect_digits(self, nonce: str) -> dict`:
     ```python
     url = svc.url(f"/twilio/voice/digits/{call_id}/{nonce}")          # nonce only; digits never in a URL
     await asyncio.to_thread(svc.adapter.redirect_call, session.provider_sid, url)   # REST Calls/{sid} Url=...
     return {"ok": True}        # on ProviderError: {"ok": False, "error": type(exc).__name__}
     ```
     Before the redirect, set `session.digits_redirect_until = time.monotonic() + 20`. That is enough for 32 digits
     plus the stream reconnect; the real timing is UNCONFIRMED and is measured in the live plan. While it holds,
     `relay_closed` starts no drop watchdog, and the new stream does not count as a reconnect.
   - **TwiML route:** `Route("/t/{secret}/twilio/voice/digits/{call_id}/{nonce}", digits, methods=["POST"])`, with
     the same webhook authentication and `leg_expectation` check as `answer`:
     ```python
     digits = session.voice.take_redirect_digits(nonce)          # once; None if unknown/used/expired/a code
     if digits is None:   # log ingress_rejected (reason=digits_nonce); answer the CURRENT generation's document
         return session._preserving_twiml()   # again: no digits, nothing minted, never an empty <Response/>
     token = svc.issue_stream_token(call_id, f"media-g{N}")       # next generation N
     return xml(line.voice.twiml.response(line.voice.twiml.play_digits_then_stream(
         digits=digits, ws_url=svc.ws_url(f"/twilio/media/{call_id}/{token}"),
         action_url=svc.url(f"/twilio/voice/connect/action/{call_id}?g={N}"), call_id=call_id)))
     ```
     The old stream ends, and Twilio plays the digits, then opens the new stream on the existing media route
     (point 4). `VoiceCall` re-attaches and sends `setup` again, which `_on_setup` already treats as a non-first
     setup.
   - **Connect action during a redirect:** whether Twilio requests the old `<Connect action>` URL when the call is
     updated is NOT FOUND in the docs. If it arrives while `digits_redirect_until` holds, `relay_action` returns
     `connect_twiml(session, welcome=None)` (a fresh stream, no digits) and does not count a reconnect.
   - **Codes never take this path.** `press_menu` and `take_redirect_digits` refuse digits that equal or contain a
     code released through `send_sealed` (kept as per-call keyed hashes, never as text). Only `origin="menu"` plans
     exist. Sealed DTMF stays local tones, so a code never enters a TwiML document or Twilio's request logs. This
     requires the point 6 `send_secret → voice.send_sealed` hook, which is how the voice path learns the code.
     Relay-shaped `sendDigits` frames are tones only and never use the fallback.
   - **The "menu did not react" signal** (`line.voice.dtmf.menu_did_not_react`). After the tones have finished
     playing (all marks acknowledged), the menu's first final utterance within `voice.dtmf_react_window_s`
     (default 8 s) decides. "No reaction" means one of:
     - an error or retry phrase ("invalid", "didn't get that", "please try again", ...);
     - a repeat of the prompt heard since the previous press: word similarity ≥ 0.9, or a reply of 4+ words that
       **all** appear in order inside that prompt (STT splits long menus into sentences).

     Anything else means the menu moved on. Silence never triggers the fallback. The rule is strict on purpose: a
     false retry would press a key in a sub-menu ("For *new* reservations, press 1" is not a repeat), while a
     missed retry only leaves the repeated prompt to Hermes. The fallback is tried once per press. The prompt that
     triggered it goes to the transcript (`record`) but not to Hermes (no `prompt` frame), so Hermes does not press
     the same keys again.
10. **Desktop/store (optional).** `voice_*` events are logged through `voice_event`. A `voice_seconds` field on the
   call snapshot can come from `session.voice.connected_seconds`. "Say this", take-over and hang-up already work
   through the relay-shaped frames.

  - If every retry fails, `voice_failed` is called once. On the real engine the call ends `failed` /

## 6. Round 5: review R1 delta 7 fixes (`evidence/reviews/R1-DELTA7-voice.md`)

**N9: socket ownership from the end of the handshake.**
- `provider.connect_owned(connector, url, headers, timeout)` runs the handshake as its own task. If the caller is
  cancelled or times out while the handshake finishes, the socket that was created anyway is closed. This covers
  the Python 3.11 `wait_for` race, where a result that completes during cancellation is lost.
- `GrokRealtimeProvider.connect` closes the socket on any unsuccessful exit after the handshake: a failed initial
  `session.update` send, a readiness error or timeout, and cancellation, which is re-raised.
- `XaiStreamingTranscriber.start` adopts the socket with no await in between.
- `VoiceCall` owns a provider or transcriber from the start of its setup (`_unadopted`) until it adopts it. Each
  setup runs in its own task (`_run_setup`). `close()` cancels the setups in flight, waits for their cleanup (up
  to 5 s), and closes anything not adopted. It cancels only the setup, never the task hosting it (for example the
  Twilio stream reader). A setup that finishes after the call closed is discarded at once.

**N10: no credential in logs or exception text.**
- `websockets_connector` passes `transport_logger()`, a private `hermes_line.voice.transport` logger with its own
  INFO level, so root or `websockets` DEBUG never enables the client's header logging.
- A redacting filter drops any record that mentions Authorization or bearer, even if someone lowers that logger
  to DEBUG.
- Handshake failures surface only as the exception type (`ProviderUnavailable("connect failed: InvalidStatus")`),
  with no cause or context chained.

**Tests (`tests/l5/test_review_r1d7.py`, 8):**
- **N9:**
  - The reviewer's `probe_voice.py` case with the assertion inverted: socket closed, no provider, nothing
    unadopted.
  - `close` during an in-flight session setup: socket closed, zero open sockets, stream reader not cancelled.
  - A failing initial `session.update` closes the socket.
  - A handshake that completes after cancellation is closed, for both Grok and STT.
  - STT cancelled mid-handshake, `close` during the STT handshake, and `close` with an adopted STT stream: zero

- **N10** (the real `websockets` client against a 127.0.0.1 server, root and `websockets` loggers at DEBUG,
